== ALOLI conventions

This shard follows the
https://github.com/aloli-crystal[aloli-crystal/*] ecosystem
conventions:

* `VERSION` constant read at compile-time from `shard.yml` —
  cannot drift.
* CLI accepts `__SHARD__ help [<sub>]` (UX-standard equivalent
  of `--help` + per-subcommand focus).
* Default branch is `production` (never `main`).
* SemVer 3-digit for original creations, 4-digit for ports of
  Ruby gems.

To start a new shard with these conventions, see
https://github.com/aloli-crystal/shard-template[aloli-crystal/shard-template].
