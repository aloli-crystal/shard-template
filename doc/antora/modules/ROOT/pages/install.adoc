= Installation

== Comme dépendance d'un autre shard

Ajoutez à votre `shard.yml` :

[source,yaml]
----
dependencies:
  __SHARD__:
    github: aloli-crystal/__SHARD__
    version: "~> 0.1"
----

Puis :

[source,shell]
----
shards install
----

== En local pour développer

[source,shell]
----
git clone git@github.com:aloli-crystal/__SHARD__.git
cd __SHARD__
shards install
crystal spec       # lancer les tests
----
